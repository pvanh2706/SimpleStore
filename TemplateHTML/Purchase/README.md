# SimpleStore Purchase Management Interactive HTML Reference v1.0 — Candidate

Interactive single-file prototype based on the approved Purchase Management design board.

## Open
Open `index.html` directly in Chrome/Edge. No CDN, package install, API, backend, or local server is required.

## Interactive flows
- Purchase list
- Filter drawer
- Purchase detail with tabs: Overview / Products / Payments / History
- Create Purchase wizard: Supplier → Products → Payment → Confirm
- Edit Purchase
- Cancel Purchase with reason
- Print simulation
- Demo states: empty / no-result / loading / error

## Target
Primary desktop review viewport: **1536 × 1024**.

This file is a visual/workflow prototype only; it is not a domain/API contract.
