# SimpleStore Debt Management Interactive HTML Reference v1.0 — Candidate

Mini-project HTML tương tác cho module **Công nợ**, bám theo ảnh thiết kế Debt Management đã duyệt.

## Cách mở
Mở `index.html` trực tiếp bằng Chrome/Edge. Không cần CDN hoặc server.

## Luồng tương tác
- Tổng quan công nợ
- Chuyển tab Khách hàng / Nhà cung cấp
- Search và Bộ lọc
- Chi tiết công nợ khách hàng
- Thu tiền khách hàng
- Chi tiết công nợ nhà cung cấp
- Trả tiền nhà cung cấp
- Giải thích công nợ
- Lịch sử giao dịch / lịch sử thu trả
- Demo states: rỗng, không kết quả, loading, error, not-found, no-permission, stale-data/refresh

## Visual target
- `design-reference.png`
- Desktop review viewport: **1536 × 1024**
- Giữ design language nhất quán với Product/Purchase/Inventory/Today.
