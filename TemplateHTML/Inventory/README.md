# SimpleStore Inventory Management Interactive HTML Reference v1.0 — Candidate

Mini-project HTML tương tác cho module **Tồn kho**, dựa trên ảnh thiết kế Inventory Management đã duyệt.

## Cách mở
Mở `index.html` trực tiếp bằng Chrome/Edge. File là self-contained, không cần CDN hay server.

## Luồng tương tác
- Tổng quan tồn kho
- Bộ lọc tồn kho
- Chi tiết sản phẩm trong tồn kho + tabs Tổng quan / Lịch sử / C14
- Điều chỉnh tồn kho 3 bước
- Kiểm kho 4 bước
- Lịch sử biến động tồn kho
- Search và chip trạng thái

## Visual target
- Primary target: `design-reference.png`
- Desktop review viewport: **1536 × 1024**
- Giữ visual language nhất quán với Product/Purchase interactive prototype.

## Lưu ý
Đây là design prototype, không phải production implementation hay authority mở rộng business scope.
