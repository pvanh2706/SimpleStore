# SimpleStore Product Management Interactive HTML Reference v1.0 Candidate

Một prototype HTML duy nhất chứa các state Product Management và tương tác mô phỏng.

## Luồng có thể mở trực tiếp
- Product List mặc định
- Bộ lọc sản phẩm
- Thêm sản phẩm
- Menu thao tác từng dòng
- Chi tiết sản phẩm
- Sửa sản phẩm
- Điều chỉnh tồn kho
- Kiểm kho 3 bước
- Lịch sử tồn kho
- Ngừng kinh doanh

## Cách dùng
Mở `index.html` bằng Chrome/Edge. Không cần server, package, CDN hay asset ngoài. Ảnh sản phẩm được nhúng trực tiếp vào HTML.

Đây là prototype UX/visual để Product Owner review, chưa phải production implementation.
