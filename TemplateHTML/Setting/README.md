# SimpleStore Settings / Appearance Interactive HTML Reference v1.0 — Candidate

Mini-project HTML tương tác cho màn **Giao diện** trong Settings.

## Cách mở
Mở `index.html` trực tiếp bằng Chrome/Edge. File self-contained, không cần CDN hoặc server.

## Tương tác
- Đổi tên cửa hàng và xem preview cập nhật ngay
- Đổi logo minh họa
- 6 màu chủ đạo: Emerald / Ocean / Indigo / Terracotta / Slate / Dark POS
- Light / Dark / System
- Density: Compact / Standard / Comfortable
- Toggle logo trên hóa đơn / bo góc / tabular numbers
- Đổi ảnh nền login minh họa
- Khôi phục mặc định
- Lưu thay đổi (prototype)
- Preview đồng thời Sales / Login / Receipt

- `design-reference.png`
