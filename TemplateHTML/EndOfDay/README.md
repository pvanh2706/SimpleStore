# SimpleStore End-of-day Interactive HTML Reference v1.0 — Candidate

Mini-project HTML tương tác cho module **Đóng ngày / End-of-day**.

## Luồng tương tác
- Danh sách ngày và trạng thái đóng ngày
- Xem báo cáo đóng ngày
- KPI và các bảng chi tiết
- Cơ cấu thanh toán (donut)
- Cơ cấu doanh thu theo nhóm hàng
- Drawer giải thích số liệu (Explainability)
- Quy trình đóng ngày 3 bước nằm ngang

## Cách mở
Mở `index.html` trực tiếp bằng Chrome/Edge. Không cần CDN/server.

## Visual target
`design-reference.png`, viewport desktop 1536×1024.
